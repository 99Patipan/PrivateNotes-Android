# Private Notes (Android)

โน้ตส่วนตัวแบบเข้ารหัส เก็บในเครื่องเท่านั้น (Kotlin + Jetpack Compose + Room)

## ฟีเจอร์
- ล็อกด้วย PIN 6–12 หลัก (ต้องยืนยัน PIN ตอนตั้งค่า) และลายนิ้วมือแบบผูกกับ Keystore (CryptoObject)
- ล็อกอัตโนมัติเมื่อออกจากแอปเกิน 30 วินาที (`AUTO_LOCK_GRACE_MS` ใน `NotesViewModel`)
- ใส่ PIN ผิด 5 ครั้งขึ้นไปจะถูกหน่วงเวลาแบบทวีคูณ (30 วินาที → สูงสุด 1 ชั่วโมง)
- `FLAG_SECURE` กันภาพหน้าจอ/Recents
- สำรอง/กู้คืนเป็นไฟล์เข้ารหัส `.snote` (ต้องยืนยันรหัสผ่านตอนสำรอง และยืนยันก่อนกู้คืนทับ)
- แก้ไขโน้ตมีร่างค้างตอนหมุนจอ และถามก่อนทิ้ง/ลบ

- หน้ารายการสไตล์ ColorNote: แถบสีด้านซ้าย พื้นพาสเทล วันที่ด้านขวา เรียงตามเวลา/สี/ชื่อ กรองตามสี และค้นหา
- เลือกสีโน้ตได้ 8 สีจากหน้าแก้ไข (เปลี่ยนภายหลังได้) สีถูกเก็บและสำรองไปกับไฟล์ `.snote`

- ส่งไฟล์สำรองไป Google Drive ได้จากกล่องสำรองข้อมูล (ปุ่ม "ส่งไป Google Drive / แชร์" หรือเลือก Drive ในหน้าบันทึกไฟล์) ไฟล์เข้ารหัสแล้วเสมอ ชื่อไฟล์มีวันที่-เวลา

## โมเดลความปลอดภัย
- โน้ตเข้ารหัสด้วย AES-256-GCM โดยใช้ data key (DEK) แบบสุ่ม; title/body ผูก AAD กันสลับคอลัมน์
- DEK ไม่ถูกเก็บแบบเปล่า: เก็บเป็น `DEK → AES-GCM(PBKDF2(PIN, 310k)) → AES-GCM(Android Keystore, StrongBox ถ้ามี)`
  PIN ผิดจึงถอดรหัสไม่ได้เลย (ไม่มี PIN hash ให้โจมตี) และไฟล์ที่คัดลอกออกจากเครื่องไม่มีประโยชน์
- ลายนิ้วมือ: DEK อีกสำเนาถูกเข้ารหัสด้วยคีย์ Keystore ที่ต้องสแกนนิ้วทุกครั้ง และถูกยกเลิกเมื่อมีการลงทะเบียนนิ้วใหม่
- ไฟล์สำรอง `PNOTES02`: PBKDF2-SHA256 600k รอบ (เก็บใน header), header เป็น AAD; ยังอ่านไฟล์เก่า `PNOTES01` ได้
- ข้อจำกัด: เครื่องที่ root/ถูกเจาะขณะปลดล็อกอยู่ยังอ่าน memory ได้ และถ้าลืม PIN จะกู้ได้จากไฟล์สำรองเท่านั้น

## Build
GitHub Actions (`.github/workflows/android.yml`) จะรันเทสต์และ build debug APK ให้ แล้วอัปโหลดเป็น artifact
ในเครื่อง: เปิดด้วย Android Studio หรือรัน `gradle wrapper --gradle-version 8.9` แล้ว `./gradlew assembleDebug`

## ย้ายจากเวอร์ชัน 1.0
รูปแบบการเก็บคีย์เปลี่ยน เวอร์ชันนี้อ่านโน้ตของ 1.0 โดยตรงไม่ได้ ให้ **สำรองข้อมูลในแอปเดิมก่อน**
จากนั้นถอนการติดตั้ง ติดตั้งเวอร์ชันใหม่ ตั้ง PIN แล้วกู้คืนจากไฟล์สำรอง
(APK debug ที่ build จาก CI ลงชื่อคนละคีย์ จึงติดตั้งทับของเดิมไม่ได้อยู่แล้ว)
